# Welcome

OpenSage-ADK is an AI agent development framework where AI writes its own agent. If you are new here, this page points you to the right starting place.

## New to OpenSage-ADK?

Start with the [Quick Start](quick-start.md). It walks you through running your first agent end-to-end.

## Customize Your Agent

Every OpenSage-ADK agent is configured through a single TOML file. The [Customize Agents](customize/index.md) section walks through it as a progression: from minimal config, then LLM, sandbox, MCP tools, history, plugins, ensembles, Neo4j, and build, and ends with a [complete example](customize/complete-example.md) you can copy.
